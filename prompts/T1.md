## Task

Make `tape scan` work end to end:

1. Walk the four roots from `scan::source_roots()` (Claude, Codex sessions,
   Codex archived_sessions, pi sessions). Skip anything that isn't `.jsonl`.
2. Extract `session_id` and `group` per tool:
   - **pi** — file `<enc-cwd>/<ISO-ts>_<id8>.jsonl`; the authoritative id is the
     first line's `{"type":"session","id":"<uuid>",...}`. Group = that id.
   - **Claude** — file `<enc-cwd>/<uuid>.jsonl`; id = filename stem. A session
     also owns the directory `<uuid>/subagents/agent-*.jsonl`; **every one of
     those files must carry the parent's `group`**, so the set archives
     together. `session_id` for a subagent file is the parent uuid.
   - **Codex** — `rollout-<date>T<time>-<uuid>.jsonl`; id = trailing uuid
     (also present as `session_meta.payload.id` in the first line — prefer the
     line, fall back to the filename). Group = id.
3. `blake3` the file's exact bytes → hex in `FileEntry.blake3`.
4. Set `quiescent = false` for any file whose mtime is within
   `scan::QUIESCENCE_MINUTES` (10 min) of now. Report them, never archive them.
5. Write the manifest atomically (write temp → fsync → rename) to
   `paths::manifest_path()`, and make `tape scan --json` print it.
6. Human-readable output: per-tool file counts, per-tool total bytes, number of
   Claude groups with subagents, number of non-quiescent files.

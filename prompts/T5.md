## The porting rule

`render_trace.py` is a design you are **translating, not redesigning**. Keep its
CSS/JS/HTML verbatim — copy the `HTML_TMPL` block (line 646 onward) across as a
`const` and fill it from Rust. The specific behaviours that make it good:

- density modes: skim / read / full
- one-turn-at-a-time paging (JS, no server round-trips)
- resizable left timeline rail
- emoji-per-tool badges via `tool_icon` + `bash_verb` / `bash_chain` (lines
  261–352) — the verb extraction from a shell command is the interesting part
- **edit/write calls rendered as old/new diffs, not JSON blobs**
- tool output collapsed past 1400 chars, with a "repeats" callout
- `highlight()` (line 209) — its hand-rolled syntax highlighting, ported
  honestly rather than dropped
- `esc()` everywhere; nothing from a transcript may reach the page unescaped

**Do not port the regina-specific parts:** `find_context_files`,
`context_seen`, `injected_context`, `find_meta` (lines 84–208) read files from a
live source repo, which the archive host does not have. Session metadata comes
from the index columns (`sessions.cwd/git_branch/model/started_ms/...`) and from
`Session` — not from disk. If a page wants something the index does not carry,
say so in your report; do not go read the source tree.

## Build and deploy loop

```sh
# debra (dev + acceptance)
export CARGO_TARGET_DIR=$HOME/Code/tape-target TAPE_HOME=/tmp/tape-t3-full
cargo build && ./../tape-target/debug/tape serve --addr 127.0.0.1 --port 8799
# browse http://127.0.0.1:8799

# CT (deploy) — egress is still open, so pulling works
git push origin main            # from debra
ssh rk@192.168.50.108
cd ~/tape && git pull --ff-only && export PATH=$HOME/.cargo/bin:$PATH
cargo build --release
TAPE_HOME=/var/lib/tapes ./target/release/tape serve --addr 192.168.50.108 --port 8799
# browse from debra: http://192.168.50.108:8799
```

Gotchas already paid for: the shared `CARGO_TARGET_DIR` means one shared
`debug/tape` — build and run in one command and check `--help`; an interrupted
build can leave a stale binary, fix with `cargo clean -p tape`; quote commit
messages with single quotes (backticks get executed).

## Constraints

- **No new crates.** `axum` and `tokio` are already in `Cargo.toml` and are
  enough. If you want `pulldown-cmark`, `maud`, `askama`, anything else — stop
  and say why; the dependency list is deliberate.
- **Read-only.** No handler may write, and nothing in `web.rs` may open a
  source tree. The archive is append-only; the UI must be incapable of changing
  it.
- **No auth, no TLS** (decision D3) — but bind to the LAN interface, never
  `0.0.0.0` on the CT, and say so in the startup line.
- SQLCipher: the index opens only with `TAPE_HOME/db.key` (or `TAPE_DB_KEY`).
  A wrong key must stay a loud error, not an empty page.
- No `rm`. Scratch goes in `/tmp/tape-t5-*`.
- Do not invoke `ark`.

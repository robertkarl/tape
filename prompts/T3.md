# Prompt → implementing agent, T3

Paste this as the opening message in the T3 worktree session (`t3-index`).

---

You are implementing **T3** of the `tape` transcript archiver: turn stored
transcripts into a queryable index. `SPEC.md` → `PLAN.md` → `TASKS.md` first;
decisions D1–D8 are locked. T1 (`scan`) and T2 (`store`) are merged into `main`
and work — build on them, do not reinvent them.

## Ownership

You own: `src/db.rs`, `src/parse/mod.rs`, `src/parse/pi.rs`, `src/parse/claude.rs`,
`src/parse/codex.rs`, `src/ingest.rs` (new), and tests for them.

Do not edit: `Cargo.toml`, `Cargo.lock`, `src/types.rs`, `src/paths.rs`,
`src/main.rs`, `src/scan.rs`, `src/manifest.rs`, `src/store.rs`, `src/web.rs`,
`src/render/`. If a shared type blocks you, **stop and report it**. Add no
crates — `rusqlite` already carries `bundled-sqlcipher` and `chrono` features.

## Task

1. `db::open` — SQLCipher via `rusqlite` `bundled-sqlcipher`, key from an env
   var or a file under `TAPE_HOME`; apply the schema from **PLAN.md §4 verbatim**
   (hosts / sessions / messages / tool_calls / blobs / vanished). Idempotent
   migrations; the DB must be rebuildable from the blobs alone.
2. Parsers → the canonical `Session`/`Turn`/`ToolCall` in `src/parse/mod.rs`:
   - **pi** — envelope `timestamp` is ISO-8601 but `message.timestamp` is
     **epoch milliseconds** (`> 1e11` ⇒ ms). Carry `usage`/`cost`, `stopReason`,
     `errorMessage`, and the `model_change` / `thinking_level_change` /
     `session_info` lines into index columns.
   - **claude** — `uuid`/`parentUuid` chain, `isSidechain`, and the
     `<session>/subagents/agent-*.jsonl` set: `scan` already groups those files
     under the parent's `group`, so ingest a group as one session.
   - **codex** — only `response_item` feeds turns; `session_meta`,
     `turn_context`, `world_state`, `token_usage_record`, `compacted` become
     index columns, never dropped text.
3. `tape ingest --store DIR` — for each blob: decrypt, decompress, parse, upsert
   into the index. Idempotent (re-ingesting a blob is a no-op), append-only, and
   it must record which blob is newest per `(session_id, host)`.
4. A parse failure must **not** lose data: log the blob hash into a
   `parse_failures`-style report and keep going. The blob is the source of
   truth; the index is disposable.

## Acceptance

- Row counts reconcile with blob counts: every one of the **846 blobs** on this
  machine appears in `blobs`, and per-tool `sessions` rows match T1's counts
  (pi 292 files, claude 205 files / 99 groups, codex 356 files).
- Re-running `ingest` twice produces identical row counts (idempotence).
- Spot-check 5 sessions per tool against the raw JSONL by hand and report what
  you compared.
- The index opens only with the key: prove a wrong key fails.

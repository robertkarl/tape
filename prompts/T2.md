## Task

Make the blob store real:

1. `tape keygen` — age X25519 keypair. Write the identity to
   `paths::identity_path()` (mode 0400) and the public key to
   `paths::pubkey_path()`. **Refuse to overwrite an existing identity** — losing
   that file means the archive is unrecoverable, so clobbering it must be
   impossible.
**Do not depend on `tape scan`** — T1 is landing in parallel and its output is
not yours to wait on. `tape store` should consume the `Manifest`/`FileEntry`
types that already exist in `src/types.rs`, and your tests should build those
structs themselves (blake3 over a file is three lines).

2. `tape store` — for each quiescent entry in the manifest: zstd (level
   `store::ZSTD_LEVEL`) then age-encrypt to the **public key**, write to
   `paths::blobs_dir()/<blake3-of-plaintext>.tape`. Blob identity is the hash of
   the ORIGINAL plaintext, so a grown session becomes a new blob and the old one
   stays untouched.
3. Writes are **write → fsync → rename**, temp file in the same directory. A
   process killed mid-write must never leave an unreadable file at a final name.
4. `tape verify` — walk every blob, decrypt, decompress, re-hash, compare to the
   filename. Report per-blob failures and a final tally. Non-zero exit on any
   failure.
5. Idempotence: storing an already-present blob is a no-op, never a rewrite.
